New Features

Action Move & Copy

You can now move any action/folder anywhere in the app, better managment, easy to use, multi select support, maximum flexabilty.


Presets now persist Menu Mode settings (enabled state and icon).
Menu Mode moved from global setting to per preset.
You can enable/disable per preset on the setting screen,
and also quickly toggle between the mode using new hotkey Option + Shift + Command + M (You can change it of course)
Or using new toggle option in the ExtraBar context menu.

Improved Shiori Bookmarks
UI UX fixes,
AND new lifetime plan for extrabar users - fixed price no limits.



Cleanup

Removed "Import from Preset" from the folder action library — the move/copy workflow now covers this use case, reducing
UI redundancy.
